# HR message design lab

Изолированный Telegram-бот для проверки вариантов оформления реальных сообщений рабочего HR-бота.

- Не подключается к HH, Google Sheets, календарю или рабочей базе.
- Использует только вымышленных кандидатов и тестовые сценарии.
- Сообщения повторяют реальные случаи и подписи исходного бота.
- Кнопки показываются только в тех случаях, где они есть в рабочем интерфейсе; действия являются демонстрационными.
- Первый пользователь, отправивший `/start` в личном чате, становится владельцем лаборатории.

Команды:

- `/next` — показать следующий случай;
- `/all` — показать все случаи;
- `/list` — список случаев;
- `/show 8` — показать один случай.

Для запуска создайте рядом файл `.env` с `BOT_TOKEN=...`, затем выполните:

```text
node index.mjs
```

Самопроверка без подключения к Telegram:

```text
node index.mjs --self-test
```
